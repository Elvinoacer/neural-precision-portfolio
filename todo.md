Your client is right. The current site looks polished visually, but it is **not yet built like a high-converting sales website**. It feels more like a stylish portfolio section page, not a trust-building service funnel.

I inspected the uploaded Next.js project. The main issues are:

1. **It is a single-page portfolio**, not a conversion funnel.
2. **The copy is too generic**: “Precision Data. Seamless Assistance.” sounds premium but does not clearly tell a buyer why they should hire her now.
3. **No strong proof layer**: no case studies, results, process, turnaround time, client value, sample outputs, testimonials, or credibility anchors.
4. **Weak CTA flow**: “View Services” and “Let’s Connect” are okay, but not sales-driven.
5. **The contact form is not functional**: it uses `action="#"`, so it only looks like a form but does not actually convert unless connected.
6. **Hero video loads aggressively** with `preload="auto"`, which can hurt mobile performance.
7. **Services are too broad**: Data Annotation, Customer Service, VA, LLM Training are mixed together without separate buyer journeys.

The rebuild should become a **premium service website for hiring Everlyn Linda**, not just a portfolio.

## High-priority technical fixes

### 1. Make contact form work

Currently:

```tsx
<form action="#" method="POST">
```

This is not enough.

Use one of these:

* EmailJS
* Resend
* Formspree
* Next.js API route + Resend
* WhatsApp redirect after form submission

Best simple approach:

```txt
Next.js API route → Resend email → success toast → WhatsApp fallback
```

---

### 2. Do not preload hero video aggressively

Current:

```tsx
preload="auto"
```

Change to:

```tsx
preload="metadata"
```

Or remove the video on mobile and use the portrait/optimized background instead.

For mobile conversion, speed matters more than cinematic video.

---

### 3. Split pages properly

Use this structure:

```txt
app/
  page.tsx
  services/page.tsx
  about/page.tsx
  portfolio/page.tsx
  contact/page.tsx
```

Create shared components:

```txt
components/

  ServiceCard.tsx
  CTASection.tsx
  ProcessSection.tsx
  ProofSection.tsx
  ContactForm.tsx
```
